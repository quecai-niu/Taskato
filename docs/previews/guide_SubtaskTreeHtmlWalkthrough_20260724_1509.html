1. 先建立整体工作方式

这份页面不是由一段代码完成的，而是四层代码互相配合。先记住下面四层，再看具体行号会容易很多。

1 HTML

负责父任务、子任务、按钮、复选框和输入器的结构。

2 CSS

负责颜色、缩进、连接线、悬停显示和折叠动画。

把按钮和对应的父任务分组关联起来。

处理新增、完成、进度计算、展开和折叠。

推荐阅读顺序：不要一开始就钻进 JavaScript。先看 HTML 中的 data-add-to、data-toggle、data-children， 再看 JavaScript 如何读取它们。

8. 进度统计：第 615–653 行

第 620–624 行：统计直属叶子任务
输入一个分组，返回完成数和总数 
function directLeafStats(group) {
  const leaves = [...group.children].filter(element => element.matches('[data-leaf]'));
  const complete = leaves.filter(element => element.querySelector('.task-check').checked).length;
  return { complete, total: leaves.length };
}

[...group.children] 把类似数组的 HTMLCollection 转成真正数组，之后才能使用 filter()。

第 626–648 行：父任务自动完成
行号逻辑
627–633计算 upgrade 的进度；全部完成后自动勾选父任务并添加完成样式。
635–643计算 release 的进度并更新顶级父任务。
645–647扫描全页面叶子任务，更新“还有多少项待完成”。
650–653单个复选框变化后更新自身样式，再重新计算所有父级。
当前预览存在统计偏差：第 635–639 行把整个 upgrade 分支算作一项，因此顶级进度会从 HTML 中写的 2 / 5 变成 1 / 4。
与正式 Taskato 一致的递归叶子统计 
const releaseLeaves = [...groups.release.children]
  .filter(element => element.matches('[data-leaf]'));
const completedReleaseLeaves = releaseLeaves
  .filter(element => element.querySelector('.task-check').checked).length;

const releaseComplete = completedReleaseLeaves + upgradeStats.complete;
const releaseTotal = releaseLeaves.length + upgradeStats.total;
修正结果：嵌套分支中的每一个叶子任务都参与进度，初始状态正确显示为 2 / 5。

9. 动态创建任务：第 663–721 行

第 667–683 行：createTaskNode()
根据标题创建一条新任务 
function createTaskNode(title) {
  const node = document.createElement('article');
  node.className = 'task-node new-node';
  node.dataset.leaf = '';
  node.innerHTML = `
    <div class="task-row">
      <input class="task-check" type="checkbox" aria-label="完成${title}">
      <div class="task-copy">
        <div class="task-name"></div>
        <div class="task-meta"><span>刚刚添加</span></div>
      </div>
      <div class="task-actions"></div>
    </div>`;
  node.querySelector('.task-name').textContent = title;
  node.querySelector('.task-check')
    .addEventListener('change', event => setCompleteState(event.target));
  return node;
}
行号作用
668创建新的 article 元素。
669添加任务样式和进入动画。
670把新任务标记为叶子任务。
671–679生成任务内部结构。
680用 textContent 安全写入可见标题。
681给新复选框绑定完成状态事件。
682把创建好的节点返回给保存逻辑。
正式代码注意：第 673 行把标题直接插入 aria-label 模板字符串。如果标题包含引号， 应改用 setAttribute()，避免属性内容被破坏。

选择器绑定的行为
[data-toggle]点击进度胶囊后展开或折叠对应分组。
[data-add-to]点击新增入口后，在指定父任务中打开输入器。

11. 预览 HTML 与最终正式界面的差异

预览 HTML 仍有的旧逻辑

  • 子任务列表底部仍有“添加下一项”。
  • 顶级进度把嵌套父任务当作一项。
  • 移动端隐藏悬停按钮后依赖底部入口。

正式 WPF 已采用的最终逻辑

  • 只有悬停显示的“添加子任务”入口。
  • 进度统计所有后代叶子任务。
  • 进度胶囊接管展开和折叠。
  • Enter 保存，Esc 清空并关闭输入。
学习时的判断：把这份 HTML 当作“视觉与交互原型”；业务规则以正式 WPF 实现为准。

12. 术语表

DOM
浏览器解析 HTML 后形成的页面节点树。
叶子任务
没有子任务、可以直接完成的最末级任务。
父任务
包含子任务，其完成状态由后代决定的任务。
伪元素
::before 等由 CSS 生成、无需额外 HTML 的视觉元素。
data-* 属性
HTML 提供给 JavaScript 使用的自定义数据。
可选链
?.，对象不存在时安全返回，而不是立即报错。
模板字符串
使用反引号包裹，可以跨行并通过 ${...} 插入变量。
事件监听器
等待点击、输入或状态变化，然后执行指定函数。
