# Taskato 项目记忆

更新时间：2026-10-12

## 当前架构决策

1. C# Service/ViewModel 是任务、计时器和设置的唯一业务事实来源；React 只能调用 `WebBridgeService` 白名单协议。
2. 每日总结只读取仍然有效的完成记录。任务完成后取消会保留在活动日志，但不继续出现在每日总结。
3. `TaskActivityRecords` 是只追加时间线。写任务与写活动必须在同一 SQLite 事务中完成；旧库只回填可证明事实，并保留迁移边界。
4. 数据恢复不在运行中的连接上覆盖 SQLite；只暂存已校验内容，在下次启动连接数据库前替换，并先保存回滚副本。
5. 番茄钟使用绝对截止时间计算剩余时长。DispatcherTimer 只负责刷新 UI，系统休眠和 UI 卡顿不能改变业务耗时。
6. WebView2 是唯一工作区 UI；故障时只显示可诊断错误和 retry（重试）入口，不再维护旧 WPF 工作区回退。
7. WebView2 用户数据默认位于 `%LOCALAPPDATA%/Taskato/WebView2`，自动烟测可覆盖为隔离目录；浏览器缓存不得写入或打包进便携发布目录。
8. 专注统计只读取新增 `PomodoroFocusSessions`/`PomodoroFocusSegments`：Working 与 Resting 的 active（有效）区间计入，Paused 与 CompletionPending 等待不计入；旧历史不推算。
9. 番茄钟自然完成和提前完成统一进入 CompletionPending；停止仍表示放弃。番茄钟只保存专注会话，不再自动创建推进记录。
10. “记录推进”只保留在任务详情页，新增记录默认勾选归属当前详情任务；用户可取消勾选保存为无所属，或通过任务选择器改为其他任务。
11. 任务状态为“未开始 / 进行中 / 已完成”。任务首次新增推进记录时由未开始变为进行中；手动完成变为已完成；取消完成时根据是否已有推进记录恢复为进行中或未开始。删除最后一条推进记录不自动回退状态。
12. 父任务的推进记录默认只看本任务，可切换为包含子任务；任务详情展示次数、每条开始/完成/创建时间、单次时长、总时长和最近推进时间。
13. 每日总结展示今日推进记录，并允许修改内容、所属任务和时长；专注时长与专注统计的有效总时长一致，读取番茄钟有效工作与休息区间，任务完成耗时和手动推进耗时作为独立记录耗时展示，三者不重复相加。
14. 任务完整内容的第一行是统一界面标题；任务树、详情、选择器、历史、总结、专注统计和导出均使用第一行，编辑器仍保存和显示完整内容。
15. 未完成的同级子任务先按优先级从高到低、再按创建时间从新到旧显示；同优先级的新建子任务位于较旧任务上方，已完成项仍排在其后。
16. 所有任务选项统一复用带搜索、完整路径、排序和已完成开关的 `TaskPicker`，视觉基线采用每日总结补录选择器。
17. `PomodoroTimelineEvents` 只追加保存真实阶段变化、完成提醒及按钮选择；阶段结束时间与实际弹出提醒时间分别记录。右侧时间链默认折叠，按持久化计时器槽位查询最近 100 条；阶段结束或暂停按统计会话的运行区间显示累计进行了多久，开始按上一阶段结束时间显示暂停了多久，恢复显示本次暂停时长，不受提醒和选择事件影响，无对应计时数据时不推算；与专注统计共用串行写入队列，关闭时随统计队列刷新。

## 发布边界

- 当前 GitHub 发布版本：2.40.0，对应标签 `v2.40`。
- 发布包使用 .NET 8 `win-x64` 自包含模式；安装包负责检测 WebView2 Evergreen Runtime。
- 自动静默更新和代码签名尚未启用。正式公众分发必须在受控 CI 中使用发布者证书签名。
